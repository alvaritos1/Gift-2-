PASO 2: Probar Localmente (2 minutos)
──────────────────────────────────────

1. Abre el archivo "index.html" en tu navegador
2. Haz clic en "ENTRAR A NUESTRO UNIVERSO"
3. Prueba hacer clic en los corazones
4. ¡Funciona! ✨


PASO 3: Desplegar en GitHub Pages (15 minutos)
──────────────────────────────────────────────

A. Crea cuenta en https://github.com/signup

B. Crea nuevo repositorio en https://github.com/new
   - Nombre: regalo-para-rubi
   - Público: Sí

C. Abre PowerShell en tu carpeta y ejecuta:

   git init
   git add .
   git commit -m "Galaxia de Amor para Rubi 💖"
   git remote add origin https://github.com/TU-USUARIO/regalo-para-rubi.git
   git branch -M main
   git push -u origin main

D. En GitHub:
   - Settings → Pages
   - Source: Deploy from a branch (main, /root)
   - Save

E. ¡Tu página estará en:
   https://TU-USUARIO.github.io/regalo-para-rubi/

Guía completa: Lee "DESPLIEGUE_GITHUB_PAGES.md"

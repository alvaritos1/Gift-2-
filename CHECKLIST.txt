💡 TIPS Y CONSEJOS
==================

🎨 Consejos para imágenes:
  • Asegúrate de que estén centradas y bien compuestas
  • Usa colores que combinen con la temática (tonos cálidos)
  • Optimiza el tamaño para carga rápida
  • Prueba en mobile para ver cómo se ven

🎵 Consejos para música:
  • Elige una canción romántica o alegre
  • Duración: 3-5 minutos (puedo repetirse)
  • Volumen moderado (evita ser muy fuerte)
  • Prueba que sea audible en móvil

🌐 Consejos para despliegue:
  • Crea un repositorio con nombre significativo
  • Usa descripción clara en GitHub
  • Haz el repositorio público
  • Comparte el link de GitHub Pages (no el repositorio)

🔒 Consejos de privacidad:
  • Puedes hacer el repositorio privado si lo deseas
  • GitHub Pages funciona igual
  • Solo quien tenga el link verá la página
  • Ideal para mantener la sorpresa

🆘 EN CASO DE PROBLEMAS
=======================

❌ "No puedo descargar imágenes"
✅ Soluciones:
   • Usa Unsplash, Pexels o Pixabay (gratis)
   • Toma fotos con tu teléfono
   • Crea ilustraciones en Canva
   • Pide a amigos fotos relacionadas

❌ "La página no se ve bien en móvil"
✅ Soluciones:
   • Abre F12 en navegador
   • Activa "Toggle device toolbar"
   • Ajusta viewport en index.html (ya está hecho)
   • Prueba diferentes tamaños

❌ "Los corazones no funcionan"
✅ Soluciones:
   • Revisa consola F12 para errores
   • Asegúrate que script.js esté en raíz
   • Recarga la página (Ctrl+F5)
   • Intenta otro navegador

❌ "Las imágenes no se ven en GitHub Pages"
✅ Soluciones:
   • Verifica que estén en carpeta "imagenes/"
   • Nombres exactos (mayúsculas)
   • Sube de nuevo con "git push"
   • Espera 2-5 minutos
